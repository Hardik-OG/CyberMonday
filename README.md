# CyberMonday — E-Commerce Web Application

CyberMonday is a Java-based e-commerce web application designed to
showcase products, discounts, pricing, and stock availability through
a modern shopping interface.

## Technologies Used

- Java
- JSP (JavaServer Pages)
- Jakarta Servlets
- JDBC
- MySQL
- Maven
- Apache Tomcat
- HTML, CSS, and JavaScript

## Features

- Product catalogue backed by MySQL
- Product search
- Category-based filtering
- Discounted price and savings calculations
- Stock availability display
- Product details popup
- Responsive, modern storefront interface
